## Struktur Program
- `latihan/01_buat_list.py`: Membuat dan membaca list.
- `latihan/02_indeks_slicing.py`: Indeks dan slicing.
- `latihan/03_manipulasi_list.py`: Mengubah list.
- `latihan/04_agregasi_nilai.py`: Statistik dasar.
- `latihan/05_filter_kelulusan.py`: Menyaring nilai lulus.
- `latihan/06_fungsi_statistik.py`: Fungsi rata-rata.
- `praktik/analisis_nilai_mahasiswa.py`: Analisis nilai mahasiswa.

## Cara Menjalankan
Jalankan terminal dari folder utama proyek.

Contoh:
`python latihan/01_buat_list.py`

Untuk program utama:
`python praktik/analisis_nilai_mahasiswa.py`
